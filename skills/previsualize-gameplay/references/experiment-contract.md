# Gameplay Previsualization Experiment

## Brief

Record one decision question, decision owner, deadline, current engine state, fixed references,
implementation constraints, and 2–4 mutually exclusive hypotheses. Each hypothesis must change one
primary variable.

Examples:

- camera distance: near vs medium vs wide;
- VFX intensity: readable vs spectacular;
- environment: warm daylight vs cold fog;
- boss reveal: immediate silhouette vs delayed reveal.

## Control rules

Hold duration, aspect ratio, anchors, engine screenshot/FOV, prompt structure, provider settings,
candidate count, and review rubric constant. Use comparable seed groups where supported.

## Decision matrix

Have design, art, and engineering score:

- gameplay readability;
- target emotion;
- visual identity;
- implementation difficulty;
- performance/technical risk;
- divergence from current mechanics.

Record the chosen hypothesis, rejected alternatives, open risks, and the smallest engine prototype
that can test feasibility. Generated video never closes a feasibility question.
