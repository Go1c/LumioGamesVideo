# Safety, Rights, Cost, and Disclosure

Before a remote or paid generation:

1. List the provider/model, files to upload, number of variants, target duration/resolution, and
   whether outputs will be published or shipped in a game.
2. Confirm the reference image may be used for generative processing and commercial output when
   applicable.
3. Require explicit consent for a recognizable person's likeness or voice.
4. Check provider/model territory, acceptable-use, attribution, disclosure, and commercial terms.
5. Keep credentials in the host/client secret store. Never place tokens in plugin files, prompts,
   manifests, command history examples, or generated packages.

Do not generate deceptive gameplay claims, imitate a real person without authority, or infer that a
generated attack frame proves gameplay mechanics. Store provenance for anchor, prompt, provider,
model, seed, output, frame edits, matte method, and packaging scripts.

For public/shipping outputs, record the target storefront/platform's AI-content disclosure decision.
This plugin provides an audit trail, not legal clearance.
